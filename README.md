# Multimodal Emotion Recognition Using Speech and Text Analysis

# Project Overview
This project implements a multimodal emotion recognition system using speech and text analysis. The speech modality uses MFCC feature extraction and a CNN classifier, while the text modality uses BERT-based classification. A fusion mechanism combines both modalities for final emotion prediction.

# Features
- Speech Emotion Recognition using CNN
- Text Emotion Recognition using BERT
- MFCC Feature Extraction
- Multimodal Fusion
- Emotion Prediction from Audio Files

# Technologies Used
- Python
- PyTorch
- Transformers
- Librosa
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

# Dataset
TESS (Toronto Emotional Speech Set)

# How to Run

1. Open the notebook in Google Colab
2. Upload the TESS dataset
3. Run all cells sequentially
4. Upload a `.wav` file for testing
5. Run the prediction function

# Output
Input Audio → Predicted Emotion
